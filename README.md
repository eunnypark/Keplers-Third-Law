# 케플러 제3법칙 분석
### 경사하강법을 이용한 행성 공전 데이터의 비례상수 추정

## 프로젝트 소개

태양계 행성 8개의 공전 데이터를 활용하여 케플러 제3법칙의 비례상수 \(k\)를 추정하는 프로젝트입니다.

평균제곱오차(MSE) 손실함수와 경사하강법을 직접 구현하고, 학습률과 데이터 잡음에 따른 추정 결과의 변화를 분석했습니다.

## 사용 기술

- Python
- NumPy
- Matplotlib

## 주요 내용

- 케플러 제3법칙을 \(Y=kX\) 형태로 변환
- 피어슨 상관계수 계산
- MSE 손실함수 및 경사하강법 구현
- 학습률에 따른 수렴 결과 비교
- 데이터 잡음에 따른 추정 결과 비교
- 최소제곱법을 이용한 결과 검증

## 실험 결과

- 원본 데이터의 비례상수 추정값: 약 **0.9988**
- 잡음 데이터의 비례상수 추정값: 약 **0.9420**
- 경사하강법과 최소제곱법의 계산 결과 일치
